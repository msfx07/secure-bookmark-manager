About
Sandbox99 Bookmark

Sandbox99 Bookmark is a self-hosted, privacy-focused web application that lets you save, organise, and retrieve your bookmarks from any device without relying on third-party cloud services.

Key Features
  • End-to-end authentication with bcrypt password hashing
  • Optional TOTP two-factor authentication (2FA)
  • Automatic page metadata scraping on bookmark creation
  • Folder and tag organisation with full-text search
  • Netscape HTML export and import for cross-browser portability
  • Bootstrap 5.3 responsive UI with native light / dark mode
  • Bookmark lifecycle timestamps (created, last modified, and last accessed)
Technology Stack
  • Backend: Python 3.11 / Flask 3.1 / Gunicorn
  • Database: SQLite3 (file-backed, no external server required)
  • Container: Docker + Docker Compose
  • Frontend: Bootstrap 5.3 CDN with Bootstrap Icons
